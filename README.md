This project was an attempt to create a useable mouse that could be controlled through hand motion detected by a camera. 
The concept was to provide a way to control the device without needing to be in position to comfortably operate a mechanical hand mouse. For example, perhaps while lying down, or while watching a show, where the show is streamed from your device onto a larger screen, this program would allow the convenience of actions like pause, play, tab switching, and the like from the comfort of your couch. Unfortunately, the program rapidly developed to be complicated, and I have since left it unfinished.
